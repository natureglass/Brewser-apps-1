# Brewser Apps — 1

**Extension capacity** for the Brewser published app catalogue.

The primary catalogue lives in [Brewser-apps](https://github.com/natureglass/Brewser-apps). GitHub repositories have practical size limits, and an app catalogue only grows — so when the primary repository approaches capacity, newly published apps land here instead. Same catalogue, same rules, more room.

Nothing changes for anyone:

- **Users** browse one catalogue in Brewser Runtime and at [brewser.io](https://brewser.io) — which repository an app is stored in is invisible.
- **Developers** submit through [brewser.io](https://brewser.io/submit/) exactly as before; the pipeline decides where an approved app lands.
- **Every app here** has passed the same automated security scanning (static analysis and taint tracking), review, and staging as apps in the primary repository.

This repository is served via GitHub Pages at **play1.brewser.io**. Until the primary catalogue fills up, expect it to be mostly empty — that's the point.
